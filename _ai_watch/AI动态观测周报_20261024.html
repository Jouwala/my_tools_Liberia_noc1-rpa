四条最值得记住的判断

核心结论

  • 开放权重第一次在综合智能指数上咬住闭源。 Kimi K3.1 Pro（10/23）拿到 Artificial Analysis 智能指数 55 分、全球第四，距 Claude Opus 5.5 的 58 分只差 3 分 —— 而上一代 K3 是 44 分，一个季度涨 11 分。它在 Terminal-Bench 4.0 拿到 65.7%，超过 GPT-6 Astra 的 58.2%。注意：权重本身要到 11 月 4 日前才放出，目前还没有自托管实测。
  • 「开放权重」「免费」「本地可跑」本周被彻底拆成三件事。 2.8T 的 Kimi K3.1 Pro 和 816B 的 Muse Spark Open 都属于「权重开放但本地跑不动」—— 后者官方方案要两台 512GB 内存的 M5 Ultra Mac Studio。真正能在消费级硬件上跑的是 Muse Glimmer 30B（Apache 2.0，4-bit 约 17GB，24GB 显存起步）、Recursive Flint（40B 总参 / 2.5B 激活，MacBook Pro 125+ tok/s）和 Nemotron 3.5 Bolt E4B（4GB 显存）。选型第一问应该是「我能跑吗」，而不是「它便宜吗」。
  • Agent 的瓶颈已经从模型挪到沙箱与凭证治理。 Perplexity 把 Computer 的沙箱层 SPACE 开源（Apache 2.0）：每个任务一个 Firecracker microVM，凭证留在沙箱外，median 创建延迟从 185ms 降到 60ms。同期 Vercel 调查 1000+ 家 SaaS，发现只有 8.4% 支持安全认证。模型能干活了，但让它安全地干活是另一道工程题。
  • 厂商自报榜单的行间差距，比模型之间的差距更值得看。 Kimi K3.1 Pro 在 Terminal-Bench 4.0 拿 65.7%，距 Claude Opus 5.5 的 66.4% 仅 0.7 分；但同一模型在 Terminal-Bench Science 上只有 38.1%，而 GPT-6 Astra 是 68.1%。选型要看你的任务落在哪一行，而不是总榜名次。

📦 开源 · 沙箱基础设施

Perplexity「SPACE」agent 沙箱

Computer agent 的底层隔离层开源，Apache 2.0。Rust 写的，基于 AWS 的 Firecracker microVM —— 每个 agent 任务一台独立 VM，任务结束即销毁；凭证留在沙箱外，由宿主机网关统一管控出网策略；支持快照暂停 / 恢复 / 分叉成多个并行沙箱，滚动快照最长保留一周。自 7 月起承载 Computer 全部会话。

Apache 2.0可自托管需 Linux + KVM + btrfs
安全与性能均为厂商自测：官方安全机构跑了 216 次，9 个前沿模型（Opus 5.0、GPT-5.6 Sol、Kimi K3 等）在 108 次逃逸尝试中无一突破虚拟机边界，但 4 个模型绕过过部分网络检查（DNS 欺骗 + 共享 CDN 路由），Perplexity 称已修复且复测未再成功，无第三方复现。median 创建延迟 185ms → 60ms（3.1 倍），p90 447ms → 89ms（5 倍）。Akamai / Crusoe / CoreWeave 已宣布提供托管版本。

方法与局限
· 数据来源：25 个 X 账号的公开时间线，经 r.jina.ai 免登录通道抓取（2026 年 10 月 24 日）。抓取到的仅是每个账号可见的首屏推文，非完整历史，覆盖范围受账号活跃度与置顶推文影响 —— 例如 karpathy 首屏含 7 月、8 月旧帖，jeffdean 首屏含 9 月内容。
· 长推文在未登录视图下会被截断：X 对超长正文折叠并显示「Show more」，展开需登录，因此本周 97 条推文中约 28 条正文不完整（已去掉末尾的 Show more 标记，但句子本身在源侧即被截断）。引用推文内容已并入正文，但两部分均可能各自被截断。
· 抓取通道说明：jina 的 markdown 渲染对部分账号会返回「降级」结果（缺 status 链接、时间戳与互动量），因此本周统一走 HTML 渲染模式取结构化数据，再还原成与清洗脚本一致的中间格式；互动量取自页面 engagement 区域的计数（回复 / 转发 / 点赞 / 浏览）。
· 排序依据：互动量（点赞 + 浏览量加权）排序，非编辑推荐；分类归属由人工判断。
· 噪声账号（DeepSeekAI 内容为搬运、TogetherAI 抓到骚扰内容、ylecun 为政治吐槽）未纳入。
· 涉及厂商自报的基准与数据均已标注来源性质，未做独立验证；标 ⚠️ 者为厂商或评测方自报。Artificial Analysis 智能指数属第三方评测机构数据，其余基准多数来自厂商自测。
· 模型发布信息与免费额度信息经联网搜索交叉核对，以厂商官方博客 / HuggingFace / 官方定价页为准，补充了 X 首屏未覆盖的条目（如 Kimi K3.1 Pro 基准与开放时间、Muse Spark 授权条款、Qwen 免费额度的三个坑、Claude 订阅 API 额度）。
