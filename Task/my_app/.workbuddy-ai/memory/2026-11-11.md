## 表浏览器 `?page=tables`（如意报「Totota 搜得到、totota 搜不到」+ 要求列名加过滤）
- 根因：生产 `DB_MODE=pg`，**PostgreSQL 的 `LIKE` 大小写敏感**（SQLite 默认只对 ASCII 不敏感），`backend/routers/tables.py::_build_search_clause` 直接 `"col" LIKE '%kw%'`。修法：左值 `LOWER(...)`、参数也 lower，双模一致；顺手用 `ESCAPE '!'`（不用反斜杠，避开 PG `standard_conforming_strings` 差异）把搜索词里的 `%` / `_` 当字面量。
- 新增列头筛选：`col_filters` JSON 随 `data` / `export` 下发，服务端以 AND 叠加到全局搜索；**刻意不用 antd 的本地 `onFilter`** —— 服务端分页时它只筛当前页 20 行，翻页就漏。四种 op：`contains` / `equals` / `in` / `empty`；列名白名单取 `_column_metadata`（**不能用 `_safe_ident`**，真列名常带空格/中文），值全部参数化。全局搜索的 OR 链**必须加括号**，否则与列筛选 AND 组合时优先级出错。
- 新端点 `GET /api/tables/{t}/column-values?column=&limit=200`：全表去重、按出现次数降序，供「选值」勾选；空值不进候选（`IN` 匹配不到 NULL），另给「仅空值」模式。
- 前端 `TableBrowser.tsx`：每个列名右侧漏斗 → `Popover` 面板（Segmented 模式 + Input / Checkbox 候选值 + 应用 / 清除 / 隐藏此列）；已启用筛选在表格上方常驻 Tag；翻页、导出、切表联动。⚠️ 面板内**不能用 antd `Select`**（下拉 portal 到 body，点它会触发 Popover 的 click-outside 把面板关掉），全用内联组件。
- 顺手修 sqlite 分支：`pragma_table_info` 的 `notnull` 在 SQLite 3.49 被当成保留字，裸写报 `near "notnull": syntax error`，已加双引号。
