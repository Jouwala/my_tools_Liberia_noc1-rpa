## VMAX 投诉诊断前端完善 + 终版截图（2026-10-31）

**① 修掉评分证据弹窗被裁（真实根因不是 max-height）**

现象：点四维评分卡弹出的证据窗被视口右下裁掉，`bottom=1328 > vh=1100`。
- 第一层原因：`.dcm-body` 缺 `flex:1 1 auto; min-height:0; overflow:auto`，
  flex 子项默认 `min-height:auto` 撑破了 `.dcm-modal` 的 `max-height:88vh`。
- **真正根因（更隐蔽）**：`DraggableClickModal` 渲染在诊断卡的 DOM 内部，而
  `index.css:420` 那组卡片玻璃态给 `.ant-card/.wh-card` 挂了 `backdrop-filter`。
  **`backdrop-filter` 会让该元素成为 `position:fixed` 子元素的包含块**，
  于是 modal 的 fixed 变成「相对卡片固定」，JS 写的 `top:522px` 渲染成
  `rect.top=882.5`（差值 = 卡片在文档里的偏移 360.5）。
- 判据（记住这条）：**`el.style.top` 与 `getBoundingClientRect().top` 不相等，
  就沿祖先链查 `transform / filter / backdrop-filter / will-change / contain`**。
- 修法：`createPortal(..., document.body)`，包含块恒为视口，与卡片样式彻底解耦。
  另把 `.dcm-overlay` 的 `display:flex` 去掉（flex item 会被 `align-items:center`
  预置偏移，和 JS 定位叠加）。
- 加了两条防回归断言：弹窗 `rect` 完整落在视口内、`.dcm-body` 存在且有独立可滚区。

## ⑤ RAN 端到端验证：查出并修掉 fetch_all 漏传号码（P0）

会话 `6bc547e1` 收尾时留下的「RAN 真机验证未跑通」被归因为「上游门户会话被占满」。
本次重试后证明**归因错了**，真实原因在代码：

**根因**：`backend/services/vmax_cca/vmax_diagnosis.py::fetch_all(start, end)` 早期签名
没有 `msisdn`，`_page_through` 里调 `query_table("", ...)` → 条件成
`{"field":"msisdn","value":"","type":"1"}` → 上游如实按空号码过滤，**四个源恒 0 条**。
RAN 靠 1300/1100 解析 IMSI，于是必然报「无 IMSI 映射」。

**判定证据**（同表同窗口 `fact_5gsa_psup_flow` / 10-30 17:00~10-31 16:59）：
`/api/vmax-xdr-records`（带号码）**2484 条** vs `/api/vmax-diagnosis` **0 条**。

**修法**：`fetch_all(msisdn, start, end)` 必填、空号码 `ValueError`；msisdn 一路传到
`_page_through` → `query_table` 首参；router 传 `normalized`。文件头补纪律 4。

**修后实测**（`231773777115`，13:59~16:59，8.0s）：
1300 **512** / 1100 **792** / 32 RAN **216** / 1301 0，IMSI `618070113596304`。

**顺带修的三处字段契约**（mock 永远发现不了，只有真数据才暴露）：
1. 小区列是 **`cell`**，`cellname`/`cell_name` 全空 → 逐小区表曾全塌成「未知小区」。
   规则层新增 `cellOf()` 三级回退；`VmaxEvidenceTimeline` 的下钻首选列也补 `cell`。
2. `cqi` 216/216 行 = **65535**（哨兵）→ 平均 CQI 曾显示 65535。新增 `cqiOf()` 取 (0,31]。
3. `ulsinr` / `phr` 出现 **255**（哨兵）→ 会把 P10/均值拉高，结论从「干扰」翻成「正常」。
   新增 `sinrOf()` 取 (-30,40)、`rsrpOf()` 取 <0。**哨兵值比缺数据更危险**。
4. `rat_name` / `interface_name` 全空串（`$rat` 只有代码 6），制式分布只能显示 `—`（未做码表）。
