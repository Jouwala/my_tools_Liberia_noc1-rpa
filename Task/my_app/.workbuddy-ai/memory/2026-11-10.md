## 排查：`/MsPortal/viewer.html?no=66&gid=BO View&lang=en` 又出现中文「2026年11月10日」

**结论：中文不在门户、也不在 my_app，而是第三层 iframe（UME iMonitor 原版大屏）按浏览器语言渲染的时钟**，与 `?lang=en` 无关。

三层实测（Playwright 遍历 `page.frames`，脚本 `TMP/t_imonitor_lang_probe.py` /
`t_imonitor_lang_header.py` / `t_imonitor_lang_fix_probe.py`）：
| 层 | URL | 中文浏览器下 |
| --- | --- | --- |
| 0 MsPortal 外壳 | `viewer.html?no=66&gid=BO View&lang=en` | 全英文，`<html lang=en>` ✅ |
| 1 my_app iframe | `/myapp/?page=imonitor`（**embedSrc 没带 lang**） | 全中文（标题「UME iMonitor 大屏」、按钮「刷新/重新登录」…） |
| 2 8088 大屏 iframe | `https://localhost:8088/iui/guard-imonitor-iui/#/screen/screen-view?screen_id=1` | `div.text-title` = `2026年11月10日 08:49:26` |

- 上游 `scripts.1dbae2af98db8fc5622d.js` 的 `$Boot.bootConfig.getLanguage()`：
  **先读同源 storage `language-option`（JSON 字符串），没有就退回 `navigator.userLanguage || navigator.language`**；
  等于 `zh-CN` → `zh-CN`/moment 中文 locale（`YYYY年M月D日 HH:mm:ss`），其它一律 `en-US`（`YYYY/MM/DD HH:mm:ss`）。
  语言还缓存在 `top.zteFrameworkCurrentLanguage`；请求头 `language-option` 也由它带。
- `main-es2015.*.js` 里 `this.language = getLanguage() || 'zh-CN'` → `i18nSetForRoot()` 切 translate/moment locale。
- ⚠️ `<html lang="en">`（上游 index.html 硬写）**不影响**这条判定；`?lang=en` 只是 MsPortal 自己的参数。
- 对照：浏览器 `zh-CN` → 中文日期；`en-US` → `2026/11/10 08:52:26`；
  `en-US` + 强制 `Accept-Language: zh-CN` → 仍英文 ⇒ **不是请求头驱动，nginx 加 `proxy_set_header Accept-Language` 无效**。
- **「又」的最可能诱因**：2026-11-09 把 8081-8088 由 http 改成 https（修 "localhost sent an invalid response"）。
  localStorage 按 origin(scheme+host+port) 隔离，scheme 一换旧 `language-option` 全丢 →
  退回中文浏览器语言 → 中文日期复现。实测新源 localStorage 无该键。**不是代码回归**：
  HTTPS 前后的 `portal_ports.conf` 都只有 CSP / frame-bust / 登录注入三种 sub_filter，从没改过语言或日期。
- **修复入口已实证**：中文浏览器下在 8088 同源写
  `localStorage.setItem('language-option', JSON.stringify('en-US'))` 再刷新 →
  时钟变 `2026/11/10 08:55:50`、整页零中文。可行做法 = 8088 的 `sub_filter '</head>'`
  注入一段按 URL `lang` 写该键的脚本 + `ImonitorScreen.tsx` 把 locale 带进 8088 iframe URL；
  顺带把 `MsPortal/assets/viewer.js::embedSrc()` 补 `&lang=<LANG>`（my_app `i18n.tsx::detectLocale` 已支持 `?lang=`）。
  ⚠️ 前者要 `nginx -s reload`（会短暂中断站点，动手前告知用户），后者要 vite build 到 `_fe_dist`。
- 本轮**只诊断、未改任何生产文件**（除 TMP 下 3 个复现脚本）。
