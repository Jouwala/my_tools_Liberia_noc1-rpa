### 踩到的验证坑

`build_summary()` 里空 Domain 写的是 `''`，但 `to_excel` 后空字符串变空单元格、`read_excel` 读回 **NaN**；

## 地图滚轮缩放：内嵌在门户里时改成「先点地图」（21:50）

用户从门户侧提的需求：`http://localhost/MsPortal/` 的 Central Liberia Regional Topology
四个页签（gis / mwRealTime / realtime_alarm / packet_loss）里，地图铺满整个区块，
鼠标只要落在区块上滚轮就被 Leaflet 吃掉去缩放地图，想滚门户页面却把地图放大了。
确认口径：四个页签全改；**只在被 iframe 内嵌时生效**，独立打开 my_app 行为不变。

### 改动

- **新增 `frontend/src/components/MapWheelZoomOnClick.tsx`**：
  `isEmbeddedInPortal()` = URL 带 `mwembed=1`（门户 iframe 的 src 自带）或 `window.self !== window.top`；
  内嵌态下 `map.scrollWheelZoom` 初始关闭，`map.on('click')` 打开、`map.on('blur')` 与容器
  `mouseleave` 收回，组件卸载时 `enable()` 还原（不留副作用给下一次挂载）。
- **`GISMap.tsx`**（gis + realtime_alarm 共用）与 **`PacketLossDashboard.tsx`**（packet_loss）：
  `scrollWheelZoom={!isEmbeddedInPortal()}` + `<MapWheelZoomOnClick />`（双保险：建图那一帧就是关的）。
- **`public/mw_real_time.html`**（mwRealTime 静态页）：`applyEmbedWheelMode()` 同一套逻辑，
  `applyEmbed()` 与 `ensureLeafletMap()` **两处都要调** —— 嵌入信号（`?mwembed=1` / 顶层 postMessage）
  可能早于也可能晚于地图创建到达。
- 构建：`npm run build`（tsc + vite）→ `D:/01_RPA/Task/_fe_dist`，nginx 直接 serve 静态产物，无需重启服务。
  备份按老规矩留在原地：`*_bak_20260918_地图点击滚轮缩放前`。

### 为什么可行（前提已实测）

关掉 `scrollWheelZoom` 后 Leaflet 不注册 wheel 监听、不 preventDefault，
滚动会按浏览器默认**链式传给父页面**（内嵌页 `html,body` 是 `overflow:hidden!important`）——
实测未点击时每格滚轮门户 `scrollY` +120px，**不会变成「滚不动」的死区**。

### 验证（门户侧 `TMP/verify_topo_wheel_click.cjs`，13 项全绿）

四页签：未点击滚轮只滚门户页面、zoom 不变；点击后滚轮缩放生效且**连续滚轮一直有效**；
指针移出后自动收回。回归：独立打开 `/myapp/?page=gis` 仍 `scrollWheelZoom.enabled()=true`、
未点击直接滚轮 zoom 8→9；既有 `probe_map_tabs_framing.cjs` 取景数值与改动前一致。

### 踩坑

CDP `Input.dispatchMouseEvent` 只落在视口内 —— 地图 iframe 常在首屏之下，点击点算到 y=1202
（视口 1200）时 click/wheel 全部无效、事件探针一条不响；先把区块滚进视口再算坐标。
另外 react-leaflet v5 的 Leaflet 实例不在容器上（`_leaflet_map` 全空），
判缩放读瓦片 URL 的 z 最稳；要实例就从容器 `__reactFiber$*` 向上走 `fiber.return` 扫 `memoizedState` 钩子链。
