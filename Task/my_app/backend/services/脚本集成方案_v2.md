# 脚本集成方案 v2

## 概述

将外部独立脚本统一集成到 my_app 项目内部，通过通用任务调度框架（`task_runner.py`）实现：

- **统一管理**：所有任务注册到同一个框架
- **自定义调度**：每个任务独立的 cron 频率
- **立即执行**：API 支持手动触发
- **可扩展**：新增任务只需调用 `register_task()`

## 已集成脚本

| 原脚本 | 集成模块 | 任务ID | 默认调度 | 说明 |
|--------|---------|--------|---------|------|
| `get_eflow_table.py` + `get_eflow_realtime_alarm.py` | `eflow_api_client.py` + `sync_from_eflow_api.py` | `eflow_sync` | `22 * * * *` (每小时) | eFlow 全量数据同步 |
| `ran_ume_login.py` + `generate_daily_availability.py` | `ran_ume_service.py` | `ran_ume_daily` | `0 2 * * *` (凌晨2点) | RAN PM 数据 + 可用性报表 |
| `screenshot_site_outage.py` | `site_outage_service.py` | `site_outage_screenshot` | `0 1 * * *` (凌晨1点) | Site Outage 截图 |
| `sent_whatsapp_v2.py` | `whatsapp_service.py` | `whatsapp_send` | `0 3 * * *` (凌晨3点) | WhatsApp 消息发送 |

## API 接口

### 任务管理

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/tasks` | 列出所有任务 |
| `GET` | `/api/tasks/{task_id}` | 任务详情 + 最近执行记录 |
| `POST` | `/api/tasks/{task_id}/run` | 立即执行 |
| `POST` | `/api/tasks/{task_id}/schedule` | 更新调度频率 |
| `POST` | `/api/tasks/{task_id}/toggle` | 启用/禁用 |
| `GET` | `/api/tasks/history` | 执行历史 |

### Cron 表达式示例

```
0 2 * * *       每天凌晨2点
22 * * * *      每小时第22分钟
30 7 * * 1-5    工作日7:30
0 */4 * * *     每4小时
0 8,20 * * *    每天8点和20点
```

### 立即执行示例

```bash
# 立即触发 eFlow 同步
curl -X POST http://localhost:8000/api/tasks/eflow_sync/run

# 立即触发 WhatsApp 发送
curl -X POST http://localhost:8000/api/tasks/whatsapp_send/run
```

### 修改调度频率

```bash
# 改为每天8点执行 RAN UME
curl -X POST http://localhost:8000/api/tasks/ran_ume_daily/schedule \
  -H "Content-Type: application/json" \
  -d '{"cron": "0 8 * * *"}'

# 改为每4小时执行 eFlow
curl -X POST http://localhost:8000/api/tasks/eflow_sync/schedule \
  -H "Content-Type: application/json" \
  -d '{"cron": "0 */4 * * *"}'
```

## 新增任务方法

在 `main.py` 的 `_register_all_tasks()` 中添加：

```python
def _register_all_tasks():
    # ... 已有任务 ...

    # 新任务示例
    def _my_new_task():
        from backend.services.my_new_service import run_my_task
        return run_my_task()

    task_runner.register_task(
        task_id="my_new_task",
        name="我的新任务",
        func=_my_new_task,
        description="描述...",
        default_cron="0 6 * * *",  # 每天6点
        category="custom",
    )
```
