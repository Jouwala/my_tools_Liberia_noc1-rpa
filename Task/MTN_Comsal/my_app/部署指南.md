# MTN Comsal - Data Insight 部署指南

## 系统要求

| 组件 | 最低版本 | 说明 |
|------|---------|------|
| Python | 3.10+ | 需加入系统 PATH |
| Node.js | 18+ | 需加入系统 PATH |
| 操作系统 | Windows 10/11 | 已验证 |

## 快速启动

### 1. 拷贝项目
将整个 `my_app` 文件夹拷贝到目标电脑任意位置，例如：
```
D:\projects\my_app\
C:\Users\xxx\Desktop\my_app\
```

### 2. 双击启动
- **启动**: 双击 `start.bat`
  - 自动检测 Python / Node.js 环境
  - 首次运行自动安装前端依赖 (`npm install`)
  - 启动后端 (端口 8000) + 前端 (端口 5173)
  - 自动打开浏览器访问 `http://localhost:5173`
- **停止**: 双击 `stop.bat`

### 3. 访问地址
| 服务 | 地址 |
|------|------|
| 前端界面 | http://localhost:5173 |
| 后端API | http://localhost:8000 |
| API文档 | http://localhost:8000/docs |

## 数据源配置

### SFTP 远程同步
编辑 `backend/services/ftp_sync.py` 中的连接信息：

```python
SFTP_HOST = "10.201.47.62"
SFTP_PORT = 22
SFTP_USER = "ubuntu"
SFTP_PASS = "CloudStudio__123"
REMOTE_DIR = "/home/ubuntu/data"
```

- 调度时间：每小时第 22 分钟自动同步
- 手动同步：`POST http://localhost:8000/api/ftp/sync`
- 同步状态：`GET http://localhost:8000/api/ftp/status`

### 本地数据导入
将 Excel 文件放入 `db/` 目录，运行：
```bash
python backend/scripts/init_db.py
```

## 关键路径说明

所有路径均使用 **相对路径**（基于 `Path(__file__)`），确保可移植性：

| 文件 | 路径逻辑 |
|------|---------|
| `database.py` | `Path(__file__).parent.parent / "db" / "app.db"` |
| `init_db.py` | `Path(__file__).resolve().parent.parent.parent / "db"` |
| `ftp_sync.py` | `Path(__file__).resolve().parent.parent.parent / "db"` |
| `start.bat` | `cd /d "%~dp0"` — 使用 bat 文件自身所在目录 |

## 功能模块

### GIS Map
- 站点经纬度散点图 + 区域蒙层（凹包算法）
- 时间窗口过滤（全部/7天/30天/3月/6月/自定义）
- 点击站点下钻查看 TT/WO 明细
- 拓扑连线显示站点间关联

### TT&WO Dashboard
- 统计卡片：WO数 / Alarm Severity / Ticket Severity / SLA Status / Status
- MTTR 周趋势折线图 + TT 数量柱状图
- Domain 分布柱状图
- Root Cause / Sub Root Cause 双饼图
- WO Source / Status 统计
- 站点信息：Power Sources / 维护团队 / Power Vendor
- 所有图表支持下钻明细 + Excel 导出

### Table Browser
- 数据库表浏览器
- 分页：20/50/100/200 行每页
- 导出 Excel 按钮

## 常见问题

### 端口被占用
```powershell
# 查看端口占用
netstat -ano | findstr ":8000"
netstat -ano | findstr ":5173"
# 杀掉占用进程
taskkill /PID <进程号> /F
```

### 前端页面空白
- 确认后端已启动：访问 `http://localhost:8000/api/health`
- 检查浏览器控制台是否有 API 错误

### 数据库为空
- 先配置 SFTP 连接信息
- 手动触发同步或等待自动调度
- 或将 Excel 文件放入 `db/` 目录后运行 `init_db.py`

### GIS 蒙层边界交叉
- 已使用凹包算法（concave hull）替代凸包
- 边界自动贴合站点分布，减少区域交叉
