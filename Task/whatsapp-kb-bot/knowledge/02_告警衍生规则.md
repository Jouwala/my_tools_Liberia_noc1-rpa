## 参数明细（衍生告警的输入条件）

### mpf-outage (rule_1774597491326) — ENABLED

描述：如果某个物理站出现断站告警（2G，3G，4G，任一制式断站），时间窗内存在任一电源相关告警，则衍生电源断站告警.

参数：NE type(siteAlarmNeType)=zte.ran.bts,zte.ran.nodeb,zte.ran.enodeb; Site break alarm code(siteAlarmCode)=9910,9920,9980,9990,9970; Whether to associate site break alarm(relationSiteAlarm)=0; Power alarm NE type(powerAlarmNeType)=zte.ran.itbbu,zte.ran.sdr; Power alarm code(powerAlarmList)=198092053,198092295,198092296; Whether to associate power alarm(relationPowerAlarm)=0; Vendor ID(vendor1)=ZTE; Derivative alarm name(specificProblem)=SITE OUTAGE DUE TO POWER OFF; Time window(timeWindow1)=259200; Delay derivation time window (s)(delayCreateTimeWindow)=30; Delay recovery time window (s)(delayClearTimeWindow)=30; NE type of the root alarm(rootResType)=zte.ran.nodeb; Root Alarm Code(rootAlarmCode)=99933

### zte-4g-siteoutage (rule_1771259563772) — ENABLED

描述：一个物理站点某个制式不可用时，逻辑站点退服告警会产生，同时归属此逻辑站点的所有小区会退服产生小区退服告警，这时衍生出逻辑站点退服告警作为父告警，基础告警作为子告警，建立起父子关联关系

参数：NE type of the root alarm(rootResType)=zte.ran.enodeb; Root Alarm Code(rootAlarmCode)=9970; NE type(siteAlarmNeType)=zte.ran.enodeb,zte.ps.umac,zte.ran.itbbu; Site break alarm code(siteAlarmCode)=198094422,2114322696,198200011; Cell out-of-service alarm NE type(cellAlarmNeType)=zte.ran.enodeb; Cell out-of-service alarm code(cellAlarmList)=198094419; Whether to support CN alarms.(supportCoreAlarm)=false; Core network alarm NE type(siteCoreAlarmNeType)=zte.ps.uspp; Core network alarm code(siteCoreAlarmCode)=10000; Number of Me types(maxMeTypeNum)=1; Whether to configure only associated alarms(supportrelation)=false; Associated alarm NE types only(relationAlarmNeType)=ZTE_RAN_ITBBU,ZTE_CS_MSCS; Only associated alarm codes(relationAlarmCode)=198097062,10000; RAT(type)=4G; Whether to enable cell blocking(cellBlock)=true; ruleFlag(vendor1)=ZTE; Derivative alarm name(specificProblem)=4G site down; Delay derivation time window (s)(delayCreateTimeWindow)=10; Delay recovery time window (s)(delayClearTimeWindow)=120

### zte-4g-outage-new (rule_1770601980008) — DISABLED

描述：When a physical site of a certain RAN type becomes unavailable, the site is out of service alarm is generated. At the same time, all corresponding cells will be out of service and generating cell outage alarms. In this case, the site outage alarm is derived as the parent alarm, and the basic cell outage alarms are the child alarms, establishing a parent-child association relationship.

参数：NE type(siteAlarmNeType)=zte.ran.enodeb,zte.ps.umac,zte.ran.itbbu; Site break alarm code(siteAlarmCode)=198094422,2114322696,198200011; Cell out-of-service alarm NE type(cellAlarmNeType)=zte.ran.enodeb; Cell out-of-service alarm code(cellAlarmList)=198094419; ERA site break alarm alarm NE type(ERAAlarmNeType)=ZTE_RAN_EMS; ERA site break alarm code(ERAAlarmList)=1014; Whether to support CN alarms.(supportCoreAlarm)=false; Core network alarm NE type(siteCoreAlarmNeType)=zte.cs.uspp; Core network alarm code(siteCoreAlarmCode)=10000; Number of Me types(maxMeTypeNum)=1; Whether to configure only associated alarms(supportrelation)=false; Associated alarm NE types only(relationAlarmNeType)=zte.cs.lig; Only associated alarm codes(relationAlarmCode)=10000; RAT(type)=4G; Whether to enable cell blocking(cellBlock)=true; ruleFlag(vendor1)=ZTE; Derivative alarm name(specificProblem)=4G site down; Delay derivation time window (s)(delayCreateTimeWindow)=10; Delay recovery time window (s)(delayClearTimeWindow)=120; NE type of the root alarm(rootResType)=zte.ran.enodeb; Root Alarm Code(rootAlarmCode)=9970

### mwlink-outage-new (rule_1769172913917) — ENABLED

描述：根据链路数据表，将用户设定时间窗内发生的同链路断站告警压缩在一起，选取链路最上游的站点（Hub Site）的断站告警作为主告警，衍生新告警，其他所有的站点的断站告警挂在该告警下面作为子告警.

参数：NE type(siteAlarmNeType)=zte.ran.enodeb,zte.ran.nodeb,zte.ran.bts; Site break alarm code(siteAlarmCode)=9970,9980,9990,9910,9920; IPBH NE type(IPAlarmNeType)=zte.trm_mw.nr9150; IPBH alarm code(IPAlarmCode)=10000; Derivative alarm name(specificProblem)=MW LINK DOWN; Derivative time window (s)(timeWindow1)=180; Delay derivation time window (s)(delayCreateTimeWindow)=30; Delay recovery time window (s)(delayClearTimeWindow)=30; Associated Time Window (s)(relationTimeWindow)=360; NE type of the root alarm(rootResType)=zte.ran.nodeb; Root Alarm Code(rootAlarmCode)=9995
