3. P0 逐项方案（做完 ≈88）

P0-1 闭合 B4 —— 匿名管理员出口+7.0

  • 改：vite preview 加 --host 127.0.0.1；uvicorn 收回环；商用实例停 preview，nginx 直出 dist/。
  • 不改：保留"回环即管理员"信任，只堵"外部请求转成回环对端"的代理入口。
curl -s -m5 -o /dev/null -w "%{http_code}\n" http://192.168.100.20:7090/api/credentials   # 基线 200 → 期望 000/401
netstat -ano | grep -E "TCP.*:(7038|7090|9267)\b.*LISTEN"                                  # 期望仅 127.0.0.1

P0-2 生产脱 dev server+3.5

  • 改：vite.config.ts:83-175 中间件 + portalAuthPlugin(:190) 迁独立 server.js；加 "start":"node server.js"；start_hidden.ps1:159 改掉 npm run dev；加单实例锁。
  • 证据：现 /uniplam/ 响应含 @vite/client+react-refresh。
curl -s http://host/uniplam/ | grep -c "vite/client"   # 期望 0

P0-3 加 TLS+2.0

  • nginx 443 + 企业 CA；80 → 301 https。curl -sk https://host/ -o /dev/null -w "%{http_code}" → 200。

P0-4 堵 B3（匿名目录泄漏）+1.8

  • 改：vite.config.ts:93-105 GET 挪到 resolveCaller 之后；从 assets/data.js 与 portal-default.json 移除全部 30 处 &t= token 并作废。
curl -s .../uniplam/api/portal-default | grep -c "&t="   # 期望 0（基线 30）

P0-5 清 B5（可下载备份）+1.2

  • nginx location ~* _bak_|\.archived$|\.fixed$ { deny all; }；123 个 *.bak_* 迁出/归档；补 .gitignore。

P0-6 降 B6（轮询风暴）+1.0

  • /api/tasks 增量 / If-None-Match；TaskSyncWidget 轮询 ≥30s 且仅可见时；会话落盘 SQLite。
