## 2. P0：上线阻塞（做完 ≈ 88 分）—— 逐项可执行方案

> 全部复用团队既有的《商用就绪度检测》整改方案，此处**补充 `file:line` 定位与验证命令**。

### P0-1 闭合 B4 —— 匿名管理员出口【最严重，+7.0】
- **改**：`vite preview` 加 `--host 127.0.0.1`；`uvicorn` 收 `--host 127.0.0.1`；商用实例直接**停 preview**，由 nginx 静态直出 `dist/`。
- **不改**：按用户要求保留"回环即管理员"信任本身，只堵"把外部请求转成回环对端"的代理入口。
- **验证**：
  ```bash
  curl -s -m5 -o /dev/null -w "%{http_code}\n" http://192.168.100.20:7090/api/credentials   # 基线 200 → 期望 000/401
  netstat -ano | grep -E "TCP.*:(7038|7090|9267)\b.*LISTEN"                                  # 期望仅 127.0.0.1
  ```

### P0-2 生产脱 dev server【+3.5】
- **改**：`vite.config.ts:83-175` 的 `portal-default` 中间件 + `portalAuthPlugin`（`:190`）迁到独立 `server.js`(Express)；`package.json` 增 `"start": "node server.js"`；`start_hidden.ps1:159` 的 `npm run dev` 改 `npm start`；加单实例锁，杀 9267 双监听。
- **证据**：`/uniplam/` 现响应含 `@vite/client`+`react-refresh`。
- **验证**：`curl -s http://host/uniplam/ | grep -c vite/client` → 期望 `0`。

### P0-3 加 TLS【+2.0】
- **改**：nginx 443 + 企业 CA/自签；80 端口 301 跳 https。
- **验证**：`curl -sk https://host/ -o /dev/null -w "%{http_code}"` → 期望 200。

### P0-4 堵 B3（匿名目录泄漏）【+1.8】
- **改**：`vite.config.ts:93-105` 的 GET 挪到 `resolveCaller` 之后；从 `assets/data.js` 与 `portal-default.json` **移除全部 30 处 `&t=` token 并作废**。
- **验证**：`curl -s .../uniplam/api/portal-default | grep -c "&t="` → 期望 `0`。

### P0-5 清 B5（可下载备份）【+1.2】
- **改**：nginx 加 `location ~* _bak_|\.archived$|\.fixed$ { deny all; }`；仓库侧把 123 个 `*.bak_*` 迁出/归档；`.gitignore` 补规则；两个设计 `.md` 移出发布目录。
- **验证**：`curl -o /dev/null -w "%{http_code}" http://localhost/MsPortal/assets/portal.js.fixed` → 期望 403/404。

### P0-6 降 B6（轮询风暴）【+1.0】
- **改**：`/api/tasks` 支持 `If-None-Match`/增量；前端 `TaskSyncWidget` 轮询 ≥30s 且**仅页面可见时**轮询（`document.visibilitychange`）；会话落盘（SQLite）使重启不掉线。
- **验证**：单标签页 10min 请求数从 **212** 降到 <20。
