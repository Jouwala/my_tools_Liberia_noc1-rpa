# 2026-10-02 「冲 90」四项改动清单

> 目标：把评估分从 ≈86 推到 ≥90。四项：① 去重复逻辑 ② 可访问性 ③ 就绪度接入计划任务 ④ 扩测试。

## ① 抽取 portal-default 共享逻辑（架构）

| 变更 | 文件 |
| --- | --- |
| **新增** 共享实现 | `server/portalDefault.ts`（sanitizeGroupNames / sanitizeGroupLabels / parsePortalDefaultPayload / isLocalhostSaveRequest / createPortalDefaultHandler） |
| 改为只挂载 | `vite.config.ts`（删掉本地的两份 sanitize + 整段 handler，改调 `createPortalDefaultHandler`） |
| 改为只挂载 | `server/index.ts`（同上，删掉重复的 handler 与 sanitize） |

**效果**：dev 与 prod 不再各有一份 portal-default 逻辑，消除漂移风险。**行为零变化**（纯重构）。
