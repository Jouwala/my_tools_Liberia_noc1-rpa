# 06 user-guide.md —— 面向使用者的功能说明

> 基准日期：2026-09-22　|　项目根：`D:\01_RPA\liberia-noc_soc-数据看板统一门户`
> 面向：NOC/SOC 值班、网络优化工程师、管理层。**不需要懂代码。**

## 一、怎么打开

浏览器访问统一门户地址（部署在 nginx 的 `/uniplam/` 路径下，如 `http://192.168.100.19/uniplam/`）。

首次访问需要**登录**（账号由管理员分配）。忘记密码请联系管理员重置。

## 二、找到你要的看板

### 三种视图，按场景选

| 视图 | 什么时候用 | 长什么样 |
| --- | --- | --- |
| **卡片网格** | 日常找单个看板 | 大卡片、带描述，一屏看十几个 |
| **高密清单** | 你已经很熟，只想快点进去 | 一行一条，一屏看很多 |
| **业务分类矩阵** | 想纵览全貌 / 汇报 | 按业务域分成几块（MS 综合运维、告警监控、工单流程、网络性能、资源供应链等） |

顶栏可以切换视图。

### 搜索与筛选

- **搜索框**：直接输看板名关键词。
- **筛选**：按分类、平台（FineBI / 自研系统）、标签、部门过滤。
- **只看收藏**：勾上后只显示你星标过的。

### 平台颜色能帮你认来源

- **蓝紫色**的看板来自 **FineBI**（官方报表）；
- **青蓝色**的看板来自**自研系统**（my_app）。

一眼就能知道这张表是什么技术来源。

## 四、顶栏的实时任务部件

门户顶部会显示 my_app 后端**定时任务的实时运行状态**。每分钟自动刷新一次。

怎么看：

| 你看到 | 含义 |
| --- | --- |
| **绿色脉冲点** | 这个面板正在自动刷新，数据是活的 |
| **红点（不闪）** | 取不到数据了，此时显示的是旧内容，注意看时间 |
| 任务后面显示运行中 | 该任务正在跑 |
| 显示上次耗时/成功与否 | 最近一次运行结果 |

> 如果 my_app 后端连不上，这个部件会**自动降级**显示一份静态快照——**不会白屏**，但内容是旧的。

## 五、QC 质量指标面板

一张卡片一个质量指标。这张卡是门户上信息密度最高的部分，值得花一分钟看懂。

### 卡片上三行分别是什么

| 位置 | 内容 |
| --- | --- |
| 第一行 | **指标名称** + 图标。**左侧有 3px 竖条**：蓝=正常，玫红=异常 |
| 中间大字 | **指标数值**。绿色数字 = 有数据；灰色 `—` = **没取到** |
| 第三行 | **统计口径**（这行小字最关键——它说明这个数字是怎么算出来的）。失败时会变成失败原因 |

### 点开看明细

**点卡片任意位置**会弹出明细窗口：

- 表格列出构成这个指标的每一行数据；
- 顶部可以**搜索**；
- 底部可以**翻页**；
- 关掉窗口即可。

### 什么时候刷新

| 类型 | 刷新时间 |
| --- | --- |
| 全量指标 | 每小时 **06 分 30 秒**左右（紧跟后台数据同步任务跑完） |
| 告警类指标 | 每 5 分钟（**00 分 30 秒 / 05 分 30 秒 / …**） |

面板上会显示「更新于 hh:mm:ss」和一个**倒计时**，告诉你下次刷新还有多久。

> 鼠标悬停在刷新信息上，可以看到**两档各自的数据时间**——想知道"其余几项到底有多旧"看这里。

### 两条重要提醒

1. **`—` 不是 0。** 显示 `—` 表示**没取到数**，不是"数量为零"。统计里真的显示 `0` 时，那是**真的一个都没有**。这两者必须分清楚，否则会误判成"已经清空了"。
2. **失败时不会留旧数字。** 一旦取数失败，卡片会直接显示失败原因，**不会**把上一次的旧数字留在屏幕上冒充实时值。

## 六、切换环境（换机器 / 换域名）

顶栏**环境配置**可以一键把**所有**看板链接的 IP/域名批量换掉：

| 预设 | 用途 |
| --- | --- |
| 生产 nginx | 日常使用 |
| vite 7090 直连 | 绕过 nginx 直连前端 |
| 本机调试 | 本地开发 |

也可以用**自定义**填任意主机。切换后所有看板立即生效，不用一条条改。

> 改的是**你自己的浏览器配置**，不影响别人。

## 七、常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| **看不到新增的看板** | 看板配置存在你的浏览器里，**本地设置优先于系统默认**。点顶栏「恢复初始默认看板」即可刷新。注意：这会丢掉你的自定义，先「导出 JSON」备份 |
| 看板点开是空白的 | 目标系统可能没启动或网络不通。先看顶部任务部件是否变红 |
| 二维码手机扫了打不开 | 手机必须和门户在**同一网段 WiFi** |
| 某个 FineBI 报表点进去是目录页 | 该报表链接还是**占位**（标签写着"链接待更新"），要管理员替换成真实 URL |
| 数字一直显示 `—` | 取数失败，看卡片上的失败原因；持续失败请联系运维 |
| 英文界面出现奇怪的英文单词（如 `qc.updated`） | 该处文案缺英文翻译，反馈给开发 |
| 登录报 405 / 登录失败 | 环境异常，联系管理员（技术原因见 `architecture.md` 第二节） |
| 界面某些地方颜色不协调 | 深浅模式切换后个别部件没适配，反馈给开发 |

## 八、给你的两条约定

1. **看数字先看口径。** 卡片第三行小字写的是统计口径，不同卡片的"同类指标"可能口径不同，别直接横比。
2. **`—` 按"未知"处理，不要按 0 处理。**
