### B1. 新建生产入口 `server\index.ts`（Express）

> 说明：`server/auth/index.ts` **已导出** `portalAuthPlugin` 与 `getAuthStore`。
> 关键事实（已核实 `server\auth\routes.ts:404`）：`portalAuthPlugin` 的实现只是
> 在 `configureServer(server)` 里对每个挂载点调 `server.middlewares.use(mount, handler)`。
> 而 **Express 本身就是 connect 的超集**，所以只要给插件喂一个"假 server"，
> 把它的 `middlewares.use` 转发到 `app.use`，就能**零改动复用**全部鉴权路由。

在项目根新建 `server\index.ts`，内容（**已按 routes.ts 实际形态写，可直接用**）：

```ts
// 门户生产入口：Express 静态托管 dist + 复用既有鉴权/目录中间件。
// 与 vite.config.ts 的两个插件语义一致，只是不再依赖 vite dev server。
import express from 'express';
import path from 'node:path';
import fs from 'node:fs';
import { getAuthStore, portalAuthPlugin, resolveCaller, sendJson } from './auth';

const APP_BASE = '/uniplam/';
const PORT = Number(process.env.PORT || 9267);
const DIST = path.resolve(__dirname, '..', 'dist');
const DEFAULT_FILE = process.env.PORTAL_DEFAULT_FILE
  ? path.resolve(process.env.PORTAL_DEFAULT_FILE)
  : path.resolve(__dirname, '..', 'portal-default.json');
const AUTH_DATA_DIR = process.env.PORTAL_AUTH_DATA_DIR
  ? path.resolve(process.env.PORTAL_AUTH_DATA_DIR)
  : path.resolve(__dirname, '..', 'auth-data');

const app = express();
const authStore = getAuthStore(AUTH_DATA_DIR);
const LOOPBACK = new Set(['127.0.0.1', '::1', '::ffff:127.0.0.1']);

// —— 复用鉴权插件：喂一个假 vite server，把它注册的中间件转到 Express ——
// vite 的 server hook 可能是函数，也可能是 { handler, order }，两种都兜住。
const authPlugin = portalAuthPlugin(authStore, ['/api/auth', `${APP_BASE}api/auth`]);
const hook = authPlugin.configureServer;
const runtimeHook = typeof hook === 'function' ? hook : hook?.handler;
runtimeHook?.({
  middlewares: {
    use: (mount: string, handler: express.RequestHandler) => app.use(mount, handler),
  },
} as never);

// —— portal-default（与 vite.config.ts 同逻辑，GET 已加鉴权门）——
function isLocalhostSaveRequest(req: express.Request): boolean {
  const remote = req.socket.remoteAddress || '';
  if (!LOOPBACK.has(remote)) return false;
  const host = String(req.headers.host || '').replace(/:\d+$/, '');
  return host === 'localhost' || host === '127.0.0.1';
}
const defaultHandler = (req: express.Request, res: express.Response) => {
  const send = (s: number, p: unknown) => sendJson(res, s, p);
  if (req.method === 'GET') {
    const auth = resolveCaller(req as any, authStore);      // ← B3：登录门
    if (!auth) return send(401, { detail: '请先登录后再读取默认目录' });
    try {
      if (fs.existsSync(DEFAULT_FILE)) {
        res.setHeader('Content-Type', 'application/json; charset=utf-8');
        return res.end(fs.readFileSync(DEFAULT_FILE, 'utf-8'));
      }
      return send(404, { detail: 'portal default catalog not saved yet' });
    } catch (e) {
      return send(500, { detail: `read portal-default.json failed: ${String(e)}` });
    }
  }
  if (req.method === 'POST') {
    const auth = resolveCaller(req as any, authStore);
    if (!auth) return send(401, { detail: '请先登录后再保存默认目录' });
    if (auth.caller.role !== 'admin') return send(403, { detail: '仅管理员可保存默认目录' });
    if (!isLocalhostSaveRequest(req)) return send(403, { detail: '只有 localhost 允许保存默认目录' });
    let body = '';
    req.on('data', (c) => { body += c; if (body.length > 8 * 1024 * 1024) req.destroy(); });
    req.on('end', () => {
      try {
        const parsed = JSON.parse(body);
        const items = Array.isArray(parsed) ? parsed : parsed?.dashboards;
        if (!Array.isArray(items) || items.length === 0) return send(400, { detail: 'payload must be a non-empty dashboards array' });
        const savedAt = new Date().toISOString();
        const payload = Array.isArray(parsed) ? items : { version: 2, savedAt, groups: parsed?.groups ?? [], groupLabels: parsed?.groupLabels ?? {}, dashboards: items };
        fs.writeFileSync(DEFAULT_FILE, JSON.stringify(payload, null, 2), 'utf-8');
        send(200, { ok: true, count: items.length, savedAt });
      } catch (e) {
        send(400, { detail: `invalid JSON payload: ${String(e)}` });
      }
    });
    return;
  }
  return send(405, { detail: 'method not allowed' });
};
app.use('/api/portal-default', defaultHandler);
app.use(`${APP_BASE}api/portal-default`, defaultHandler);

// —— 静态资源 + SPA 兜底 ——
app.use(APP_BASE, express.static(DIST, { index: false, maxAge: 0 }));
app.get(`${APP_BASE}*`, (_req, res) => {
  res.setHeader('Cache-Control', 'no-cache');
  res.sendFile(path.join(DIST, 'index.html'));
});

app.listen(PORT, '127.0.0.1', () => console.log(`[portal] listening on 127.0.0.1:${PORT}, base ${APP_BASE}`));
```

> **关键两点**：
> 1. 生产服务**只监听 127.0.0.1**（`app.listen(PORT, '127.0.0.1')`），对外的 80 由 .19 的 nginx 反代——这同时消除了"门户自己暴露"的面。
> 2. 若 `express` 尚未安装：`npm i express`（package.json 里已有 express 依赖，直接用即可）。
> 3. `portalAuthPlugin` 的第二参是挂载点数组，必须含 `/uniplam/api/auth`（经 nginx 时前端走这个前缀）。
