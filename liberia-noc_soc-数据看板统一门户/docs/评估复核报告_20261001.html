2. 被漏掉的重大事实

2.1 真实主门户 = React 19 应用，而非单文件原生 JS

src/App.tsx 43KB 状态中枢27 个组件i18n.tsx 117KB / ≈1091 keytypes/dashboard.tsserver/auth/ 7 模块

技术栈（docs/AGENTS.md 原话）：React 19 + Vite 6 + Tailwind v4 + lucide-react + TypeScript；门户后端在 server/（Express/TS）。

2.2 工程实践比原评估以为的更成熟（原评估全未提及）

  • 环境单一真相源：src/config.ts 顶部注释规定主机只定义一处，优先级 localStorage > VITE_* > 硬编码；
  • 机器守卫整洁度：scripts/check-cleanliness.mjs + pre-commit 拦截探针/快照入库；
  • 已知架构坑有正式文档：/uniplam 前缀为何必须（防 405），写在 config.ts 注释里。
