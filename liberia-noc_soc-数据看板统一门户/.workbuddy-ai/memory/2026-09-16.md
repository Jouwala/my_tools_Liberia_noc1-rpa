## 环境注意（Excel 生成链路）

- `sheetagent` 的 `recalc.py` 在本机既无 LibreOffice、也无 `formulas` 包，
  直接跑会返回 `error`（公式无缓存值）。
- `formulas` 依赖较重，用 `--allow-install` 走 60s 预算会**超时失败**。
  正确做法：先建隔离 venv 并后台预装，再用该 venv 的 python 跑 recalc：
  ```bash
  "C:/Users/ZTEEMS/.workbuddy-ai/binaries/python/versions/3.13.12/python.exe" -m venv "C:/Users/ZTEEMS/.workbuddy-ai/binaries/python/envs/default"
  "C:/Users/ZTEEMS/.workbuddy-ai/binaries/python/envs/default/Scripts/python.exe" -m pip install "openpyxl>=3.1.0" "formulas>=1.3.0,<2"   # 约 3 分钟，放后台
  "C:/Users/ZTEEMS/.workbuddy-ai/binaries/python/envs/default/Scripts/python.exe" <recalc.py> <xlsx> 60
  ```
  该 venv 现已装好 openpyxl 3.1.5 + formulas 1.3.4，后续可直接复用。
